# Online math tutor

Небольшой учебный тест: ученик отправляет ответ репетитору, а репетитор через
Telegram-кнопки выбирает обратную связь, которая появляется на сайте по
WebSocket. Используются FastAPI и aiogram 3.x.

## Запуск

1. Создайте локальный `.env`, скопировав `.env.example`, и укажите в нём токен
   Telegram-бота и длинный случайный `OPERATOR_CALLBACK_SECRET`. Не публикуйте
   реальные значения.
   Создать файл можно командой PowerShell `Copy-Item .env.example .env`.
   Приложения автоматически читают `.env`; переменные окружения, уже заданные
   в системе, имеют приоритет.
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. В первом терминале запустите backend: `uvicorn main:app --host 127.0.0.1 --port 8000`.
4. Во втором терминале запустите polling бота: `python bot.py`.
5. Каждый репетитор открывает личный чат с ботом и один раз отправляет `/start`.
   Бот регистрирует репетитора; ID чата вручную вводить не нужно.
6. Откройте `http://127.0.0.1:8000/` и ответьте на задание.

Все зарегистрированные репетиторы получают ответы ученика. Кнопки: `Ответ
верный`, `Подсказка`, `Попробуй ещё раз`, `Объяснить`, `Завершить урок`.
Подсказка, повторная попытка и объяснение возвращают ученика к тесту; новый
ответ снова отправляется репетиторам. Верный ответ или завершение заканчивают
урок. Старые кнопки для уже проверенного ответа не применяются.

## Переносимый запуск через Docker Compose

Приложение упаковано для Docker Compose и не привязано к конкретному хостингу.
Подойдёт компьютер или сервер с Docker Compose, а также облачный хостинг, который
позволяет запускать контейнеры и оба процесса приложения.

1. Создайте `.env` из `.env.example` и укажите `BOT_TOKEN` и
   `OPERATOR_CALLBACK_SECRET`. Никогда не загружайте `.env` в Git или образ.
   Если токен бота когда-либо публиковался, отзовите его в @BotFather через
   `/revoke` и внесите новый.
2. Запустите сайт и Telegram-бота одной командой:
   `docker compose up --build -d`
3. Откройте `http://localhost:8000`. В логе бота можно проверить запуск:
   `docker compose logs -f bot`; остановить приложение:
   `docker compose down`.

Compose запускает отдельные контейнеры backend и бота из одного и того же образа.
Бот обращается к backend по внутреннему адресу Docker, а снаружи публикуется
только веб-сервис. Регистрации репетиторов хранятся в SQLite в томе `app_data`
и переживают пересоздание контейнера. Для другого локального порта задайте `HOST_PORT`, например
`HOST_PORT=8080`, и откройте `http://localhost:8080`.

При переносе на другой Docker-хост скопируйте код и `.env` безопасным способом,
установите Docker Compose и выполните ту же команду запуска. Для публичного сайта
настройте домен и HTTPS/WSS через хостинг или обратный прокси, поддерживающий
WebSocket. Не запускайте несколько реплик backend: сессии уроков хранятся в
памяти одного процесса и теряются при его перезапуске.

Эта переносимость относится к Docker-хостингам. Платформы только для edge/serverless
Workers, например Cloudflare Workers Free, не запускают Docker Compose и потребуют
отдельной адаптации приложения.

В комплекте есть одно примерное задание по умножению. Замените текст задания,
подсказку и объяснение в `main.py` и `static/index.html`, чтобы добавить свой
учебный материал.
